# Consulting Firm — Data Cleaning, Merge & Reporting Pipeline

A two-notebook pandas workflow that transforms three raw, messy CSV datasets from a fictional consulting firm into a single analysis-ready dataset, then generates a polished PDF report with KPIs and charts.

## Overview

Real-world business data is rarely clean. This project walks through a complete, reproducible workflow:

- **Notebook 1** cleans and merges raw engagement, timesheet, and consultant data using `pandas`.
- **Notebook 2** consumes that merged dataset to compute KPIs, build `matplotlib` visualizations, and assemble a final PDF report using `fpdf2`.

## Notebook 1 — Data Clean and Merge

### 1. Load & Inspect
Loads each raw CSV with file/folder existence checks and error handling, then inspects shape, dtypes, summary statistics, and sample rows [file:2].

### 2. Clean Engagements Data
- Detects and removes exact duplicate rows (`duplicated()` / `drop_duplicates()`)
- Fills missing values with placeholders (`"Unknown"`, `"Not assigned"`)
- Uses `value_counts()` to catch inconsistent text and whitespace, then applies `str.strip()`
- Converts mixed-format `start_date` / `end_date` strings (e.g. `November 24, 2023`, `06/20/2024`, `2025-12-15`) to `datetime64` using `pd.to_datetime(..., format="mixed")`
- Converts `project_fee` from a `$`/comma-formatted string into clean `float64`

### 3. Clean Timesheets Data
- Removes duplicate time entries
- Fills missing `engagement_id` and `notes` values (e.g. `"Unknown entry"`)
- Standardizes the `billable` column, which mixes `Y`, `N`, `Yes`, `No`, into a consistent `Yes`/`No` format
- Flags anomalies such as negative `hours_logged` values found during inspection
- Converts `week_ending` to `datetime64`

### 4. Clean Consultants Data
- Checks for duplicates and missing values
- Converts `hire_date` to `datetime64`

### 5. Fix Key Mismatches Before Merging
- Compares unique consultant names across `timesheets` and `consultants` using set differences
- Normalizes names (accents, casing, extra whitespace) with a custom `normalize_name()` function using `unicodedata` and `re` to resolve mismatches like "Tomas Herrera" vs. "Tomás Herrera"

### 6. Merge
- Joins `timesheets` → `engagements` on `engagement_id`
- Joins the result → `consultants` on `consultant_name`
- Validates the merge by checking row counts before/after and re-checking null counts

### 7. Save Outputs
Saves each cleaned table individually, plus the final merged dataset, into `Clean_Data/`.

### Notebook 1 Output

| File | Description |
|------|-------------|
| `engagements_clean.csv` | Cleaned, deduplicated engagements table |
| `timesheets_clean.csv` | Cleaned, deduplicated timesheets table |
| `consultants_clean.csv` | Cleaned consultants table |

## Notebook 2 — Metrics and PDF Report Generation

### Input
Loads `Clean_Data/data_merged.csv` produced by Notebook 1, with the same load/validate pattern (file checks, shape, dtypes) [file:1].

### 1. KPI Calculation
Computes **Consultant Utilization Rate** as a summary table, alongside supporting revenue and rate metrics derived from `hours_logged`, `project_fee`, and `billable_rate`.

### 2. Visualizations (matplotlib)
- Vertical bar chart: Revenue generated by practice
- Horizontal bar chart: Average billable rate by consultant level
- Pie chart: Engagement status distribution (Active, On Hold, Completed, Cancelled)

### 3. Report Assembly (fpdf2)
Combines an overall summary, KPI tables, and the three embedded chart images into a single formatted PDF, with an AI-generated (or rule-based fallback) narrative summary for each section.

### Notebook 2 Output

| File | Description |
|------|-------------|
| `revenue_by_practice.png` | Bar chart of revenue by practice area |
| `avg_rate_by_level.png` | Bar chart of average billable rate by level |
| `status_distribution.png` | Pie chart of engagement status mix |
| **`consulting_report.pdf`** | **Final client-ready PDF report** with KPIs, charts, and narrative summaries |

## Key Skills Demonstrated

- Duplicate detection and removal (`duplicated`, `drop_duplicates`)
- Missing data handling (`isna`, `fillna`)
- String cleaning and Unicode normalization (`str.strip`, regex, `unicodedata`)
- Data type conversion (`astype`, `pd.to_datetime` with mixed formats)
- Categorical value standardization (`map`, `value_counts`)
- Key matching and set-based validation before merging
- Multi-table `merge()` operations with validation
- KPI computation (utilization rate, revenue, average rates)
- Data visualization with `matplotlib` (bar and pie charts)
- Automated PDF report generation with `fpdf2`

## How to Run

1. Clone the repository
2. Ensure `Raw_Data/` contains the three raw CSV files
3. Open and run `Notebook_01_Data_Clean_and_Merge.ipynb` sequentially — this populates `Clean_Data/` automatically
4. Open and run `Notebook_02_Data_Visualization_and_Report_Generation.ipynb` sequentially — this reads `Clean_Data/data_merged.csv` and produces charts plus `consulting_report.pdf` in `Reports/`
